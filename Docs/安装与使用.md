# 噗噗手帐 · 安装与使用

## 安装包是什么

Pupudiary-unsigned.ipa 是为真实 iPhone 编译的未签名安装包，包含噗噗手帐和 WidgetKit 小组件扩展。支持 iOS 17 及以上；需要使用你已有的有效证书和描述文件签名后安装。未经签名不能直接安装。

请把证书、私钥、证书密码留在你自己的设备上，不用发到聊天、仓库或 GitHub Actions。

## 先确认签名工具支持什么

若要小组件显示同一份记录，并在桌面直接一键记录，签名工具必须保留小组件扩展，且两个目标都有同一个 App Group 的授权：

- 主 App：com.dandibbert.pupudiary
- 小组件：com.dandibbert.pupudiary.widget
- 共享组：group.com.dandibbert.pupudiary

主 App 与扩展需要各自匹配的描述文件，使用同一个开发者团队。只拥有一个证书并不等于获得共享组授权。不要让签名工具删除 PlugIns 中的小组件，也不要只改主 App 标识符。

没有共享组时，首次安装仍可在 App 内记录、查看、编辑和导出。小组件只会打开 App 进入记录页，不能在桌面直接写入，也不会维护另一份独立的数据。如果此前使用过共享手帐后重新签名失去共享组，App 会阻止创建分叉数据，请恢复原来的共享组签名。

完整签名步骤和离线验证工具见 [SIGNING.md](SIGNING.md)。离线验证不需要上传证书或数据，也无法替代 iPhone 上的最终安装验证。

## 日常使用

1. “记下此刻”立即保存时间，不会猜测形态、颜色或症状。误点可点“撤销”
2. “详细记录”可补填 Bristol 类型、颜色、量、费力程度、感受、用时与备注，也可修改发生时间
3. 点击任意记录进入编辑。删除先移入“最近删除”，可随时恢复
4. “记录”里按日历、形态、备注和感受查找；“趋势”只描述已保存的数据，不做健康评分
5. 设置里可导出 CSV 或完整 JSON 备份。CSV 和 JSON 都含可恢复删除记录；JSON 导入先检查，再添加新 UUID，永不覆盖已有记录
6. 提醒默认关闭。你主动开启并允许通知后，才会每天在选定时间发一次本地提醒
7. “隐私显示”隐藏小组件上的次数与时间

## 添加小组件

长按 iPhone 主屏幕空白处，点击“编辑”或“＋”，搜索“噗噗手帐”，选择小号或中号。实际位置随 iOS 版本不同。签名后请在真实 iPhone 上试一次：从小组件记下时间，打开 App 确认只增加一条。锁屏时可能需要解锁，刷新时机由 iOS 控制。

## 保管数据

无需账号，没有广告、分析追踪或开发者服务器上传。记录在设备本地，可能包含在你的 iPhone 系统备份里。卸载、重新签名或更换容器标识符前，先导出 JSON 备份。导出文件含私人健康信息，且不会由 App 额外加密，请谨慎保存和分享。

App 中的小组件预览用于查看设计，不能证明真实桌面小组件的签名、共享空间或点击行为已经通过验证。
